PETUNJUK PENEMPATAN GAMBAR / FOTO:
====================================
1. Foto Profil Anda:
   Simpan foto Anda (formal/kemeja/jas/wearpack) di folder:
   assets/images/profile/foto-ibra.jpg
   (Jika file ini belum ada, website otomatis menampilkan avatar insinyur teknis default).

2. Gambar / Screenshot Proyek:
   Simpan tangkapan layar atau foto asli proyek Anda di folder assets/images/projects/:
   - etap-sld.jpg           (Tangkapan layar Single Line Diagram / Load flow ETAP)
   - cx-programmer.jpg     (Tangkapan layar Ladder Diagram Cx-Programmer)
   - turbin-migas.jpg      (Diagram / foto riset turbin angin offshore)
   - green-school.jpg      (Foto fisik purwarupa miniatur PLTS & parkir)
   - kicad-pcb.jpg         (Foto atau 3D render PCB KiCAD Buck/Boost)

Website dilengkapi sistem cerdas: jika foto asli Anda ditaruh, website otomatis menampilkan foto Anda. Jika belum, website menampilkan blueprint teknis SVG presisi tinggi sehingga tidak akan pernah ada gambar yang rusak/pecah!
